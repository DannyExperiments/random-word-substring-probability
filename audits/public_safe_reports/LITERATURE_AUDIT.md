# Q824 primary-source comparison

Checked 2026-11-27. High confidence in the source match. A bounded primary-source search found no matching earlier lower bound for exact, position-dependent independent pattern and text. Publication priority remains unestablished.

- Amarilli, Monet, Raphaël and Salvati, *On the Complexity of Language Membership for Probabilistic Words*, STACS 2026, §7, printed p. 5:16 and PDF p. 16, pose the Shamir-language factor-probability question. The current extended version, arXiv:2510.08127v2 of 22 June 2026, retains it in §8 p. 38. “Factor” is contiguous, with independent positional marginals of explicit rational probabilities. [STACS paper](https://drops.dagstuhl.de/storage/00lipics/lipics-vol364-stacs2026/LIPIcs.STACS.2026.5/LIPIcs.STACS.2026.5.pdf#page=16) · [Extended version](https://arxiv.org/pdf/2510.08127v2#page=38)
- The extended version's Proposition 7.5, pp. 31–32, counts binary text completions admitting at least one completion of an input partial pattern. Its reduction starts from positive DNF and places one common Boolean assignment in the text. For a fixed text draw, it tests whether there is any matching pattern completion. The present probability instead weights the distinct matching pattern draws and counts each joint outcome once regardless of offsets. For example text 00 and one fair pattern bit give wildcard success 1 and independent-word success 1/2. The uniform-text wildcard variant discussed around that proposition remains outside this claim. [Proposition 7.5](https://arxiv.org/pdf/2510.08127v2#page=31)
- Shamir's original result concerns inherent ambiguity of a context-free language through repeated factorizations. Fudos, Pitoura and Szpankowski's Theorem 1 and §3 derive occurrence formulas and asymptotics in stationary Bernoulli models, including earlier analysis with random patterns. These concern a different model from arbitrary prescribed position-dependent distributions and give no hardness classification here. [Shamir (1971)](https://www.sciencedirect.com/science/article/pii/S0019995871904554) · [Fudos et al. (1996)](https://www.cs.uoi.gr/~pitoura/distribution/ipl96.pdf)
- Valiant (1979), Theorem 1, problem 7, proves counting positive 2-CNF assignments complete. Distinct variables per clause give exactly graph vertex covers; any repetitions within a clause can be dealt with as forced true variables before removing redundant clauses. Counting all covers uses the ordinary cover condition. [Valiant's paper](https://www.math.cmu.edu/~af1p/Teaching/MCC17/Papers/enumerate.pdf)
- Karp, Luby and Madras (1989), §3 and §4 pp. 432–434, sample a labelled event in proportion to its mass and keep only the least label for each outcome. The approximation and conditional sampler are applications of this coverage method to matching offsets. Independence supplies each offset mass and the corresponding conditional draw efficiently. No new general union-estimation method is claimed. [Karp–Luby–Madras](https://www.math.cmu.edu/~af1p/Teaching/MCC17/Papers/KLM.pdf)
- Searches covered the Shamir-language name and source authors, substring exact probability for random pattern and text, weighted string matching and conditional or relative approximation. Weighted text indexing usually requests fixed-pattern occurrence at each position above a threshold. i.i.d. exact complexity remains outside the new lower bound. The fixed-pattern and fixed-text polynomial cases serve as sanity checks.
